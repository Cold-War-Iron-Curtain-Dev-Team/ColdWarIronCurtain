# CWIC Crisis GUI Array Effects
#
# Purpose:
# - Startup: build one global catalog array of every possible crisis.
# - Monthly/country: rebuild arrays of the crises active in this country.
#
# Crisis ID convention:
# - 1-10   = base macro crises
# - 101-109 = compound crises
#
# Severity convention:
# - 0 = active but no severity flag found, fallback/debug only
# - 1 = low
# - 2 = medium
# - 3 = high
# - 4 = extreme
#
# Recommended placement:
# common/scripted_effects/CWIC_Crisis_GUI_Array_Effects.txt
# ============================================================

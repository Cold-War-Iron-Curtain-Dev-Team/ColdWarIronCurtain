# Historical names for the generic bookmark tank, SPAA, SP artillery and tank destroyer
# designs. Every name is the live country equipment localisation string for the matching
# legacy tier, recorded with file and line in LogDocs/Tank_Designer/data/Tank_Naming_Preset_Manifest.json.
# Recipes are copied verbatim from the generic blocks in CWIC_tank_designer_effects.txt, so
# these guards rename a starting design without altering a single stat. Each sets the generic
# block's own flag, which is what suppresses the generic fallback.

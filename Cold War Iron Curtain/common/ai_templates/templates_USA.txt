########################################################################
# USA AI DIVISION TEMPLATES
#
# Target = the historical "Division 86" heavy-division design finalized in 1980
# (the most modern US structure of the Cold War period), plus the standard
# airborne / marine / light formations of the era. The AI aims for these from
# 1949 onward and simply refines them with better equipment as tech arrives.
#   - Armored Division 86 : 6 armor + 4 mech infantry battalions
#   - Mech Infantry Div 86 : 5 armor + 5 mech infantry battalions
#   - both with self-propelled divisional artillery
# Sources: GlobalSecurity "Army 86"; battleorder.org 1980s US Army reference data.
#
# These use UNIQUE role names (usa_*) so they only apply to the USA, which is the
# only TAG whose role_ratio strategies request them (ai_templates are global and
# un-gated, so a shared role name like "armor" would affect every country).
# Battalion/support types below are all ones the mod already defines (verified
# against generic.txt, templates_stellar.txt and the USA_1960 order of battle).
########################################################################

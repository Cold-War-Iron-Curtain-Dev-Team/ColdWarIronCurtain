# ============================================================================
#  THE CHINESE QUESTION - Chinese Civil War side branch for the SOV (Stalin) tree.
#
#  The civil war is already running at game start (global flag CCW_Started), so
#  this branch is visible immediately - no entry event. The root and the wartime
#  focus are available while the war is on; the two outcome arms unlock once it
#  resolves.
#
#  OUTCOME DETECTION - no new resolution event is needed. The war is already
#  resolved in common/on_actions/wars_on_actions.txt on capitulation:
#    CHI capitulates -> ROC_lose_CCW = yes  -> ROC_taiwan + CCW_Over.
#                       The PRC wins. Historical.
#    PRC capitulates -> PRC_Lose_CCW = yes  -> ROC_Victory + CCW_Over, and
#                       SOV gets the country flag SOV_PRC_Losing_CCW.
#                       Every PRC state that is not a MAN core goes to CHI, the
#                       rump becomes a Soviet autonomy_easternbloc subject with
#                       soviet_client and soviet_repression, and it loads the
#                       PRC_SOV_50s tree. The communists have retreated into
#                       Manchuria.
#  So the two arms simply read SOV_PRC_Losing_CCW, exactly as the six focuses
#  they replace did.
#
#  Replaces six focuses removed from SOV_Stalin.txt:
#    SOV_Stalin_Save_Northwestern_China
#    SOV_Stalin_Military_Bases_in_East_Turkestan
#    SOV_Stalin_Provide_Guns_To_the_Military_Cliques
#    SOV_Integrate_Asia_into_the_Eastern_Bloc
#    SOV_Stalin_Recognize_the_Peoples_Republic_of_China
#    SOV_Stalin_Soviet_Loan_to_China
#  All six reward payloads are carried forward verbatim.
#
#  The PRC-victory arm deliberately ends at the 1956 Twentieth Congress - the
#  moment the relationship starts to go wrong. The Sino-Soviet split itself is
#  out of scope.
#
#  Shared focuses; only the root is listed in the SOV_Stalin focus_tree header.
# ============================================================================

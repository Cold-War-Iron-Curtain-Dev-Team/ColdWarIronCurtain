# ============================================================================
#  THE KOREAN QUESTION - Korean War side branch for the SOV (Stalin) tree.
#
#  Entry: sov_jvs.4 (Kim Il-sung's request, fires on day 21 from on_startup)
#  sets SOV_korea_question_active, which reveals this branch.
#
#  Replaces the four focuses that used to hang off the Mingrelian Affair /
#  Jewish Anti-Fascist Committee fork in SOV_Stalin.txt:
#    SOV_Stalin_Prepare_For_the_Korean_War
#    SOV_Stalin_Deal_with_the_Chinese
#    SOV_Stalin_Send_Infantry_Equipment
#    SOV_Stalin_Establish_the_64th_Fighter_Aviation_Corps
#  Their reward payloads are carried forward here unchanged so nothing is lost.
#
#  This branch deliberately does NOT gate the KPA. Pyongyang still launches the
#  war on its own through KPA_50s_the_fatherland_liberation_war; what Moscow
#  controls here is how much materiel, air cover and diplomatic weight the
#  Korean People's Army has when it does.
#
#  Placed to the LEFT of the main tree (which spans x 11-37) so it does not
#  compete for space with the German branches on the right.
#
#  Shared focuses; only the root is listed in the SOV_Stalin focus_tree header.
# ============================================================================

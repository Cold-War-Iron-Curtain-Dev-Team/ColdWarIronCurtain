# ============================================================================
#  THE GERMAN QUESTION - Stalin Notes side branch for the SOV (Stalin) tree.
#
#  Entry: event germanquestion.1 (auto ~1952, Stalin as leader) sets the flag
#  SOV_german_question_active, which reveals this side branch (allow_branch).
#
#  Root -> forks (mutually exclusive):
#    Path A (Historical): the Note is let die; the real 1952-56 events play out.
#    Path B (Ahistorical): pursue the Note -> fires the existing StalinNotes.*
#      negotiation, then a capstone + outcome-gated Soviet-policy sub-branches
#      (Socialist / Neutral / Western Germany).
#
#  Effects use CWIC mechanics: FPP power projection (bonus_fpp_modifier), the
#  budget system (money_to_gain + add_money_with_tooltip_effect), the German
#  political systems (SED party power, faction influence, Stasi, party
#  legitimacy, public discontent, policy sliders), influence, and the custom
#  opinion modifiers (small/medium/large_increase).
#
#  Shared focuses; only the root is listed in the SOV_Stalin focus_tree header.
# ============================================================================

# ---- ROOT -------------------------------------------------------------------
shared_focus = {
	id = SOV_sn_the_german_question
	icon = GFX_Stalin_Notes
	text_icon = Soviet_focus_style
	cost = 3
	x = 45
	y = 0
	search_filters = { FOCUS_FILTER_POLITICAL }

	allow_branch = { has_country_flag = SOV_german_question_active }

# ============================================================================
#  THE GREEK QUESTION - Greek Civil War side branch for the SOV (Stalin) tree.
#
#  Entry: sov_percentage_agreement.1, fired by SOV_Stalin_The_Percentage_Agreement.
#    option a -> SOV_Followed_Percentage_Agreements  -> historical arm  (SOV_gpa_*)
#    option b -> SOV_Rejected_Percentage_Agreements  -> intervention arm (SOV_gci_*)
#  The two arms are mutually exclusive and deliberately share coordinates, so
#  only one is ever drawn.
#
#  Replaces six focuses removed from SOV_Stalin.txt:
#    SOV_Stalin_Follow_the_Percentage_Agreements
#    SOV_Stalin_Deport_Black_Sea_Greeks
#    SOV_Stalin_Soviet_Intervention_in_the_Greek_Civil_War
#    SOV_Stalin_Assist_in_Greek_Reconstruction
#    SOV_Stalin_Establish_Military_Bases_in_Greece
#    SOV_Stalin_Push_For_Bosphorus_Border_Changes
#  All six reward payloads are carried forward verbatim.
#
#  OUTCOME DETECTION - no new resolution event is needed. The war is already
#  resolved in common/on_actions/wars_on_actions.txt:
#    "Greek Red Army"      -> PDG annexes GRE and becomes a Soviet subject.
#    "SOV Intervention Greek Victory" -> white peace, then
#       Albanian_Counter_Revolution = yes, which releases KOA and has ALB
#       declare war on it.
#  So the success arm simply reads "PDG alive, GRE gone, war over", the failure
#  arm reads "PDG gone, war over", and the Albanian sub-focus reads
#  "KOA at war with ALB".
#
#  Placed LEFT of the main tree (which spans x 11-37).
# ============================================================================

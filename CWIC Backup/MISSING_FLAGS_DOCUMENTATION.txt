NOTES
================================================================================

1. All missing flags need to be created as 32bpp, uncompressed, no color 
   palette TGA files.

2. Many of these are for country variants or alternative ideologies that may
   not be commonly used in gameplay.

3. Some flags may be intentionally missing if the country/ideology combination
   is not meant to be accessible in the mod.

4. When creating these flags, ensure they match the style and format of 
   existing flags in the mod.

5. The script fix_flag_errors.py can be used to convert any newly created
   flags to the correct format if needed.
